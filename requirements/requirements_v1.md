# Smart Traffic Signal Control System - Requirements v1

## Functional Requirements
- Adjust signal timing based on traffic density
- Emergency vehicle priority override
- Maintain safe signal transitions
- Log all system events

## Safety Requirements
- Only one direction can be green at a time
- Signal timers must be within limits
- Emergency override must dominate normal flow

## Non-Functional
- Real-time processing
- High reliability
- Auditability
